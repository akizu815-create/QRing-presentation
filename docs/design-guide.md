# QRing プレゼンテーション デザインガイド

「つながるQR」の資料は、読み手が置かれた状況を先に描く。タイトルだけを順番に読んでも、必要性、連絡の仕組み、確かめたいことが伝わるようにする。1枚につき結論を一つ置く。

## 色

| 色 | 値 | 用途 |
| --- | --- | --- |
| アイボリー | `#F7F4EE` | 基本の紙面 |
| クリーム | `#EFE9DD` | 解決方法や締めなどの紙面、注記の背景 |
| サンド | `#E2D7C2` | 仕切りの罫線 |
| ブラウンブラック | `#1F1A14` | 見出しと本文 |
| モスグリーン | `#5B6E4F` | 少量のアクセント |
| ディープモス | `#3F4F36` | 小見出し、要点、ページ番号 |
| ゴールド | `#B8954B` | 短い罫線と図解の接続線 |

明るい紙面と濃い本文を基調にする。小さな文字はブラウンブラックかディープモスで組む。

## 文字と余白

- 16:9、960 × 540の座標で設計する。PPTXでは座標1単位を1 ptとして扱う。
- 左右54、上部の章ラベルは29、フッター罫線は507を起点とする。写真の裁ち位置は紙面に応じて調整する。
- 見出しは Noto Serif CJK JP Regular の34〜38 pt、欄見出しは19〜26 pt。本文は Noto Sans CJK JP Regular の16〜18 pt。12〜15 ptは章名、ページ番号、補足に使う。
- 日本語見出しは意味のまとまりで改行し、助詞や句読点だけを行頭に残さない。本文の行間は高さの約1.4倍を目安に取る。
- 既存資料の Cormorant Garamond はラテン文字の候補。英字に使用する場合はHTMLと編集端末のフォントを揃え、PPTXを再レンダリングする。

## 写真と図解

- 写真は状況を一目で伝えられるものを選び、主要な被写体が読み取れるトリミングにする。人物を潰さないように、配置前に枠の比率でトリミングする。
- 写真を掲載する前に、出典と使用範囲を管理する。実証計画に添える写真は想定場面として扱い、実際の実証先や参加者と誤認されない文脈で使う。
- 通話図は発見者、プライバシー電話番号、登録先を線と名称で示す。操作は順序を付け、ボタン名は実画面の文言に合わせる。
- 文字、罫線、四角形で表現できる図はテキストと図形として配置する。色だけで役割や手順を区別しない。

## レイアウト

| パターン | 使用ページ | 構成 |
| --- | --- | --- |
| 写真を大きく置く表紙 | 1 | 左にメッセージとサービス名、右に人物写真 |
| 場面の提示 | 2 | 見出しと短い状況説明、街の写真 |
| 問題の対比 | 3 | 二つの短い説明を細い罫線で揃える |
| 仕組み・操作 | 4〜5 | 通話の接続図、横一列の3ステップ |
| 技術比較と用途 | 6〜7 | 方式別の比較表と、活用場面を示す4つの短文 |
| 計画と評価 | 8〜9 | 実証内容の見出し＋写真、検証項目の一覧 |
| 費用と共同検討 | 10〜11 | 費用内訳と料金協議、自治体の判断材料と実証準備 |

カードやアイコンを並べる構成、太い緑帯、影、グラデーション、装飾だけの図表、文章の詰め込みを避ける。小さな文字に押し込む前に、内容を削るか次ページへ移す。
